# CYCLE Whitepaper

## Vision

Most tokens ask holders to trust a story. CYCLE asks them to follow a loop. Value earned inside the project is aimed back at the token it came from, along a path short enough to trace by eye. The vision is a project whose mechanics fit in a paragraph and whose facts are visible the moment they exist.

## Mission

Run one closed circuit in the open. Keep the mechanics plain, keep the register honest, and keep every outside fact pending until somebody can point at it.

## The loop

1. **Gather.** Project earnings are collected in one place.
2. **Return.** The pot is pointed at the token it came from, on a visible path.
3. **Retire.** Supply that is bought back can be removed from circulation.
4. **Again.** The next lap starts from a leaner base.

**Phase 1: Foundation.** Brand, site, market board and register go live. Facts stay pending until stated.

**Phase 3: Loop.** The gather, return and retire steps run on a public path that anyone can inspect.
